Transcribe links from any site the bundled downloader supports, not just YouTube/X/LinkedIn. Any URL that isn't a direct media file (`.mp3`, `.mp4`, …) is now downloaded locally first, while direct media links are still fetched server-side. Docs and the MCP `transcribe` tool instructions clarify the two cases.
